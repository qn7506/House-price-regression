# Housing Price Prediction (Multiple Linear Regression)

This project analyzes housing price data using multiple linear regression.

## Methods
- Data preprocessing
- Dummy variable creation
- Log transformation
- Forward feature selection
- Outlier removal using IQR
- Diagnostic checking

## Final Model
Significant variables:
- area
- bedrooms
- bathrooms
- stories
- basement
- parking

## Results
R² = 0.917

Prediction was performed on a test dataset with:

MSE = 5970016.95
